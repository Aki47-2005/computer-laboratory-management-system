# COMPUTER LABORATORY MANAGEMENT SYSTEM (CLMS)

## About the Project

The Computer Laboratory Management System (CLMS) is a web-based system developed to make it easier to manage computer laboratory activities and resources. The system is intended to help with the daily operations of a computer laboratory by providing a central place where laboratory information and related activities can be managed.

This project was developed as part of our final year academic requirements in Information Technology.

## Technologies Used

The following technologies were used during the development of the system:

- **Python** – Main programming language.
- **Django** – Web framework used to develop the application.
- **HTML** – Used to structure the web pages.
- **CSS** – Used to style the application.
- **JavaScript** – Used to add functionality to the user interface.
- **SQLite** – Used as the development database.
- **PostgreSQL** – Used for the production database.

## How to Run the Project

Follow these steps to run the project on your computer:

1. Download or clone the project from GitHub.
2. Open the project folder in your code editor.
3. Open the terminal in the project directory.
4. Install the required packages by running:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the database migrations:

   ```bash
   python manage.py migrate
   ```

6. Start the Django development server:

   ```bash
   python manage.py runserver
   ```

7. Open your browser and visit:

   http://127.0.0.1:8000/
